# Credits

## Inspiration

**Sound Effect Replacer** was inspired by the approachable, drop-in asset-folder workflow of **[Easy Custom Music](https://github.com/ty-mcdk/easy-custom-music)** by **ty-mcdk**.

Easy Custom Music showed how a Gen1Recomp player can install a mod, place compatible audio in clearly named asset folders, restart the game, and immediately hear a replacement. Its v2.0.0 generation-specific layout and multiple-file playlist workflow directly informed Sound Effect Replacer 0.4.0.

**ty-mcdk explicitly gave permission to use Easy Custom Music’s code as a base for this sound-effects project** in the Gen1Recomp Discord discussion on August 17, 2026.

Sound Effect Replacer is an independent implementation for the sound-effect registry. It uses its own Red/Blue/Yellow and Gold/Silver mappings, routes exact named effects, per-move sounds, evolution-progress music, evolution-completion audio, optional species cries, and Yellow voice clips, and adds Ogg Opus detection with actionable warnings. Its v0.4.0 playlists use separate registered variants and narrowly route only assigned sound-effect targets.
